## 依赖关系与并行

```
S0 ──→ S1 ──→ S2 ──→ S3 ──→ S4 ──→ S5 ──→ S6
       (nbcore) (宿主/窗口) (面板)  (会话)  (增强)  (收口)
```

- S1(nbcore,Rust)与 S0.1/S0.2(环境、Sciter 条款)可并行;
- S2 的 2.4/2.5(纯 Qt 窗口)不依赖 Sciter,可与 2.3 并行;
- S3 与 S4 分属面板/窗口两栈,人手 >1 时可双线;
- 总计:单人全职约 **9–11 周**到 v1.0。

## 里程碑与回退预案对照

| 里程碑 | 风险触发点 | 预案 |
| --- | --- | --- |
| S0 | Sciter 条款不可接受 | 主面板回退 Qt Widgets(S3 改 QSS 路线,全局 +1 周) |
| S2 | Sciter 嵌入 Qt 消息循环异常 | 同上;窗口层(遮罩/贴图/编辑器)不受影响 |
| S6 | 内存 >140MB | 按 6.1→6.3→主面板拆视图 逐级收紧;底线:比第一代 300–500MB 低一个数量级即达成核心目标 |
| 任意 | nbcore 行为与第一代回归不一致 | 以 02 §5 真机清单为准修 core,不允许在 C++ 侧 workaround 掩盖 |
