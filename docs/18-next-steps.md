## 0. 现状一句话

产品功能面已经**超出 README 与路线图的记载**:第一代 clipboard-plus 的功能矩阵
(剪贴板历史/搜索/标签/来源筛选/多选批量/待办/截图四模式/标注编辑器/贴图/翻译五通道/OCR 双引擎)
已全部落地,另有第一代没有的:数据备份恢复、Markdown 导出、自动更新(空置)、
RapidOCR 内化、内存收口(231MB → ~130MB)。

**所以本阶段的主要缺口不在“再造功能”,而在三处:**

1. **收尾与验收未闭环**(安装器/真机清单/性能验收 —— 路线图 S6.5–S6.7 都还是空的);
2. **若干“看得见但点不动”的断点**(自动更新地址空置、自启不带 --hidden 造成开机弹面板);
3. **文档已与实物不符**(README 仍写着 Sciter、仍说 S5–S6 未完成)。
