# 16. 框选结束后浮出工具栏(形态 A 轻量版):设计方案

> 需求:关闭「框选后松开鼠标即确认」(regionAutoConfirm=false)时,
> 框选结束 → **选区底部浮出工具栏** → 编辑/贴图/保存/OCR/确认,就地完成。
> 本节为设计,**未写代码**。

## 16.0 为什么这个设定合理(与现有架构的契合)

| 现有机制 | 与浮出工具栏的关系 |
| --- | --- |
| `regionAutoConfirm=false` 时选区**已保留**、支持 8 向手柄微调(capture_session.cpp:575) | 工具栏**恰好需要一个「选区稳定态」** —— 现在就有,零新增状态 |
| 确认信号已有三路触发:Enter/双击/微调后 Enter(:682/:672) | 工具栏的「✓」只是**第四路**,发同一个 regionConfirmed |
| Esc 取消已有(:677) | 「✕」= 同一个 cancelled |
| EditorWindow 标注引擎(scene/undo/图元/compose)已形态 B 化 | **整体可复用**,不是重写 |
| 多屏 = 每屏一个遮罩(:296-307) | 工具栏跟随**有选区的那块遮罩**,天然正确 |

> 本质:把「微调模式」从**只读确认态**升级为**可操作态** ——
> 不是新造交互,是给已有的“选区保留”状态接上动作出口。

## 16.1 交互设计

    框选拖拽 → 松开鼠标(autoConfirm=false)→ 选区保留
      → 选区底部浮出单行工具栏
      → [标注▾][OCR取字][贴图][保存][✓完成][✕]
      → ✓ / Enter / 双击 = 确认(走 regionConfirmed 原通道)

### 工具栏按钮语义

> 下表为设计稿原始语义;实现已演进(长截图/透明档/二维码/翻译)。
> 现行按钮序(2026-10-25):0 标注 / 1 OCR取字 / 2 二维码 / 3 翻译 /
> 4 长截图 / 5 贴图 / 6 保存 / 7 透明 / 8 完成 / 9 取消。

| 按钮 | 行为 | 结束会话? |
| --- | --- | --- |
| 标注(画笔/箭头/…) | 选中后**直接在选区内画**;再点展开颜色/粗细 | 否 |
| OCR取字 | 对**当前选区底图**异步识别 → 弹层 | **是**(与形态 B 决策一致) |
| 二维码 | 对选区解码(核心 rqrr,毫秒级)→ 复制 + 结果面板;纯 URL 时面板给「打开链接」 | **是** |
| 翻译 | 与热键截图翻译同语义:入库+写剪贴板 → 按条目 OCR → 面板翻译页自动出译文 | **是** |
| 贴图 | 选区图贴成置顶窗口 | **是** |
| 保存 | 选区图另存 PNG | **是** |
| 完成 | regionConfirmed → 原链路入库+剪贴板 | 是 |
| 取消 | cancelled | 是 |

### 标注态的两级结构

    工具栏 [标注] ──点击──▶ 展开二级条(颜色×7 + 粗细×3 + 字号×3 + 撤销/重做)
                    ──选工具──▶ 直接在选区内画
                    ──再点[标注]──▶ 收起二级条

- 单行放不下全部(形态 B 是两行);二级条**复用同一容器**,点「标注」切换显隐;
- 撤销/重做放二级条 —— 一次标注会话内才有意义。

## 16.2 架构:标注引擎复用方式

### 提取共享类 AnnotationEngine,遮罩与编辑窗共用

    AnnotationEngine(QObject)
      - QGraphicsScene + QUndoStack + 图元构建(buildDrag/Preview/Final)
      - 工具/颜色/粗细/字号状态 + 序号自增
      - 马赛克/模糊纹理(惰性,吃底图)
      - compose(选区物理 rect) -> QImage

| | 方案甲:提取 AnnotationEngine | 方案乙:遮罩内嵌编辑窗场景 |
| --- | --- | --- |
| 复用度 | 标注逻辑**单源**,两处共享 | 复制粘贴,两处漂移 |
| 工作量 | 大(拆类 + EditorWindow 重构指向) | 小 |
| 回归风险 | 中(EditorWindow 行为须逐项不变) | 低 |
| 长期维护 | 好 | 差(改标注要改两处) |

> 建议**甲**,但**分两步**:先接浮条(OCR/贴图/保存,不动引擎),标注最后接 ——
> 它是唯一要动引擎归属的部分。

## 16.3 关键技术点

| # | 点 | 方案 |
| --- | --- | --- |
| 1 | 工具栏挂哪个窗口 | OverlayWidget **内部子项**,不新建窗口(窗口激活/置顶/多屏都不用重管) |
| 2 | 位置 | 选区底边下 8px;越出屏幕底部则翻到选区**上方**;左右夹在屏内 |
| 3 | 事件穿透 | mousePress **先命中工具栏矩形**,命中则不当作“重新框选” |
| 4 | 标注坐标 | 场景 = 冻结底图**物理像素**(与 EditorWindow 同口径);遮罩逻辑坐标 ×dpr → 场景 |
| 5 | 与手柄微调共存 | 有标注时**隐藏手柄**(标注已锚定选区,再改选区语义混乱);清空标注才恢复 |
| 6 | OCR/贴图/保存输入 | m_frozen.copy(selectionPhysical()) —— 未标注时**零 compose 开销**;有标注才 compose |
| 7 | compose 视口 | scene->render 用选区物理 rect |
| 8 | 内存 | 马赛克/模糊纹理 = 选区图一份,**用时生成、选区变更失效重建** |
| 9 | 多屏 | 工具栏只在持有选区的遮罩上 |
| 10 | autoConfirm=true | 行为**完全不变**(松手即确认,无浮条)—— 特性只在 false 下生效 |

## 16.4 与形态 B 的关系

- **形态 B 不删**:编辑窗保留,能力与浮条同源(AnnotationEngine),交互不同;
- 直通链路(regionSkipEditor=true)与默认(autoConfirm=true)**均不受影响**;
- **入口由既有设置区分**:关 autoConfirm = “框选→浮条”流;开 = “框选→编辑器”流。无新增设置项。

## 16.5 实施阶段

| 阶段 | 内容 | 交付 |
| --- | --- | --- |
| S1 | OverlayWidget 内嵌浮条(布局/命中/穿透/翻转)+ 完成/取消/OCR/贴图/保存(无标注) | 关 autoConfirm 后:框选→浮条→功能全通 |
| S2 | 提取 AnnotationEngine(EditorWindow 的 scene/undo/图元迁出,编辑窗变薄壳) | 标注逻辑单源 |
| S3 | 浮条接标注:选区内画 + 二级条(颜色/粗细/撤销) | 标注态完整 |
| S4 | 验收 --capture-toolbar-flow(翻转/穿透/标注/OCR/贴图)+ 内存回归 | 质量关 |

> 工作量:S1 中(纯 OverlayWidget 内部)/ S2 中大(重构)/ S3 中 / S4 小。
